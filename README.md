# 승부처

공 하나로 결과가 갈리는 세 장면을 폰 브라우저에서 바로 해 보는 3D 스포츠 게임.

- 9회말 2아웃: 포수 뒤 시점. 타격 커서를 공에 대고 들어오는 순간 스윙. 끝내기 15장면과 홈런 더비
- 버저비터: 슛 미터 꼭대기에서 손을 뗀다. 클러치 15장면과 3점 슛 콘테스트(70초, 최대 40점)
- 프리킥 한 방: 쓸어서 차고, 휘게 쓸면 공도 휜다. 30스테이지와 무한 도전

three.js로 그렸고 팀, 선수, 광고는 모두 지어낸 것이다.
